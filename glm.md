# App-Name / Maskottchen — Namensvorschläge

Otter bleibt Maskottchen, Name = App = Maskottchen. Anforderungen: modern, techy, rund, unisex (nicht zu weiblich/männlich), kein R nötig, X/Y/Z im Namen wäre nice, im AI-Bereich noch unbenutzt.

## Rechercheergebnis

~40 Kandidaten geprüft (Web Search + DNS), die meisten gefallen im AI-Raum: Nimbo, Kivo, Nyzo, Yuki, Umi, Aivo, Axo, Vumo, Noru, Kiki, Pip, Pluvo, Zuno usw. sind belegt. X-Kandidaten (Axo, Oxu) trafen durchgängig auf bestehende Tech-Produkte — Y und Z sind der freiere Namensraum.

## Shortlist

| **Zuyo** | Z + Y, weich-rund, eindeutig aussprechbar, sehr techy | Kein AI-Produkt gefunden — nur irrelevante Treffer (GitHub-User). `zuyo.ai` ohne A-Record. |
| **Kyzo** | knapp, prägnant, technisch | Kein AI-Produkt; nur ein Gründer-Handle «kyzo», `kyzo.ai` zeigt aktiven Server (Inhalt unklar). |

| **Uppo** | doppeltes p gibt Figuren-Charakter, passend zum Maskottchen | Kein AI-Konflikt. `uppo.com` belegt. |
| **Pono** | hawaiianisch «Rechtbeschaffenheit/Gleichgewicht», freundlich-techy | Kaum AI-Kollision, aber `pono.ai` zeigt aktiven Server — vor Übernahme prüfen. |

## Empfehlung

**Zuyo** — erfüllt den X/Y/Z-Wunsch doppelt (Z und Y), null Substanz im AI-Raum, modern ohne angestrengt, kurz genug für Sprachbefehle («Ey Zuyo»), kein Geschlecht, keine deutsche Mehrdeutigkeit. Guter Otter-Name.

## Offene Schritte

- Registrierungs-/Markencheck (Swift-Mark, App Store, EU-IPO) für Favorit.
- Domainverfügbarkeit konkret prüfen (Registrar, nicht nur DNS).
